## БЛОК 0. Правила работы кодера (протокол)

1. **Режим: только чтение.** Никаких правок файлов. Результат — отчёт.
2. **Каждый FINDING обязан иметь доказательство:** `файл:строка` + вывод команды (grep/sed/php -l), фрагмент ≤ 3 строк.
3. **Шкала критичности:**
   - `CRITICAL` — ломает функционал/безопасность/SEO-индексацию (битый PHP, утечка секретов, дубли каноникалов, 404 на ассеты из head);
   - `HIGH` — нарушает бизнес-эталон (не тот телефон, отсутствующий/лишний фикс-бар, сломанная цель Метрики);
   - `MEDIUM` — degrade UX/производительности (CLS-сдвиги, отсутствующий lazy, дубли стилей);
   - `LOW` — косметика/гигиена (пустые div, старые комментарии, .bak в docroot);
   - `INFO` — факт без отклонения (для сверки с матрицей).
4. **Секреты не трогать:** если в выгрузке окажется файл с токенами/паролями — не читать, не цитировать, отметить INFO «secrets present, not inspected».
5. **Не угадывать:** всё, что не совпадает с эталоном и не объяснено явно — выносить в блок «Вопросы архитектору», а не в FIX-рекомендации.
6. **Формат ответа:** по группам вопросов (Блок 2) таблица `№ | файл:строка | статус | комментарий`; затем сводка `CRITICAL/HIGH/MEDIUM/LOW: counts`; затем блок «Расхождения с эталоном» нумерованным списком; затем «Вопросы архитектору».
7. Проверки выполнять командами из Приложения A (единый стандарт доказательств).

## ПРИЛОЖЕНИЕ A. Команды-доказательства (стандарт)

```bash
# инвентаризация
find . -name '*.html' | sort
# фикс-бар: карта присутствия
grep -rc 'id="mobile-fixed-cta"' --include='*.html' . | grep -v ':0'
grep -rl 'id="mobile-fixed-cta"' --include='*.html' . | wc -l
# телефоны постранично
for f in $(find . -name index.html); do echo "== $f"; grep -o 'tel:+[0-9]*' $f | sort | uniq -c; done
# наши номера вне эталона
grep -rn 'tel:+79950320002\|tel:+79965117659' --include='*.html' . | grep -v 'mobile-fixed-cta'
# баланс div
for f in $(find . -name '*.html'); do o=$(grep -o '<div' $f | wc -l); c=$(grep -o '</div>' $f | wc -l); [ $o -ne $c ] && echo "$f $o/$c"; done
# php
php -l send.php
grep -n '<?php\|?>' send.php
# метрика
grep -rL '91421507' --include='*.html' .
# формы
grep -rn '<form' --include='*.html' . | head -50
# 404 ассетов: собрать локальные src/href и проверить существование
grep -rhoE '(src|href)="/[^"]+"' --include='*.html' . | sort -u
# sitemap/robots
cat robots.txt; grep -c '<url>' sitemap.xml
```
